Car Rental Service Frontend 🚗
A fully responsive frontend project for a car rental service, built with Next.js, Tailwind CSS, and ShadCN. This project features multiple pages designed with modern UI practices, ensuring a seamless user experience across all devices.

Features
⚡ Next.js: For efficient server-side rendering and dynamic routing.
🎨 Tailwind CSS: For responsive and highly customizable styling.
🖌️ ShadCN: For a consistent design system with pre-styled components.
📱 Fully Responsive: Optimized for desktops, tablets, and mobile devices.
📄 Multiple Pages: Includes home, car listings, About, and contact page.
